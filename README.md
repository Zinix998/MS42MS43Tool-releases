# MS42 / MS43 ECU TOOL - wydania

## ⬇ Pobierz

**[Pobierz instalator (najnowsza wersja)](https://github.com/Zinix998/MS42MS43Tool-releases/releases/latest/download/MS42MS43Tool-Setup.exe)**

Wszystkie wersje i opisy zmian: [Releases](https://github.com/Zinix998/MS42MS43Tool-releases/releases)

## Instalacja

1. Pobierz `MS42MS43Tool-Setup.exe` i uruchom.
2. Od wersji 1.4.0 aplikacja sama sprawdza nowe wersje - przycisk **Update to ...** na górnym pasku instaluje je jednym kliknięciem.

Sumy kontrolne: `SHA256SUMS.txt` w każdym wydaniu.
